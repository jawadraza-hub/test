# PharmaCare - Pharmacy Management System

Open `index.html` in any modern browser. No installation needed.

Features: dashboard with KPIs and 7-day revenue chart, point of sale with discount, tax and printable receipts, inventory with expiry and low-stock alerts, sales history, CSV export, backup/restore, dark mode.

Tip: Settings > "Load sample data" fills the system with a realistic demo.

Deploy: upload the folder to a GitHub repo and import it in Vercel (static site, no build settings).
Data is stored in the browser (localStorage). A shared database comes in the next phase.
